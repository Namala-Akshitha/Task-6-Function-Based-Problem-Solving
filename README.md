# Data Science Internship – February 2026
## Task 6: Function-Based Problem Solving

### Overview
This repository contains Python solutions for six real-world problems as part of the Data Science Internship – February 2026.

The problems demonstrate functions, loops, lists, dictionaries, conditional statements, arithmetic operations, and input validation.

### Problems Covered

1. **Smart Parking Lot Management System** – Tracks vehicle entries and exits, calculates current and peak occupancy, and checks parking capacity.
2. **Online Food Delivery Time Estimator** – Estimates delivery time using distance, traffic, and weather conditions.
3. **Movie Theatre Seat Occupancy Analyzer** – Calculates seat occupancy percentage and determines show status.
4. **Cloud Server Load Classification System** – Calculates average CPU usage and classifies server load.
5. **Smart Classroom Resource Usage Monitor** – Identifies overused resources and generates energy alerts.
6. **Online Event Registration Capacity Controller** – Tracks confirmed registrations, waitlisted users, and registration status.

### Technologies Used
- Python 3
- Jupyter Notebook
- Lists and dictionaries
- Functions and loops
- Conditional statements

### Project Structure

- `README.md` – Project documentation

### How to Run
1. Clone or download this repository.
2. Open the notebook in Jupyter Notebook or Google Colab.
3. Run the cells from top to bottom.
4. Review the sample inputs and outputs for each problem.
